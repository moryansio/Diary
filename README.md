
# 📖 Diary App

A simple yet powerful **Diary Application** built with Python and SQLite.  
This project allows you to create, search, and manage diary entries with flexible customization options.

---

## ✨ Features

- **Add entries by date** – store your thoughts or notes linked to a specific day.
- **Search entries**:
  - By **keyword**
  - By **exact date**
  - By **date range**
- **Delete entries**:
  - By **date**
  - Delete **all entries** at once
- **View all entries** – display your diary in a clean, organized format.
- **Settings menu**:
  - Change **theme** (light/dark)
  - Select **date format**
  - Choose **language** (English or Russian)
  - Reset all settings to default

---

## 🛠 Tech Stack

- **Python** – core logic and functionality
- **SQLite** – lightweight database for storing entries
- **Datetime module** – date validation and formatting
